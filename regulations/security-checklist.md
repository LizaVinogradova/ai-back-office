## Преамбула

Документ устанавливает признаки, требующие внимания при проверке подрядчиков и договорной документации. При выявлении любого из перечисленных ниже признаков ответственный сотрудник применяет указанное действие до подписания договора.

## Перечень red flags

1. **Red flag:** Срок активной деятельности подрядчика — менее 2 лет. **Действие:** Согласование через директора по безопасности.

2. **Red flag:** Подрядчик присутствует в реестре недобросовестных поставщиков. **Действие:** Договор не заключается.

3. **Red flag:** В договоре отсутствует раздел «Конфиденциальность» / NDA. **Действие:** Возврат подрядчику для добавления.

4. **Red flag:** Подрядчик связан с одним из учредителей АО "Просветительский Холдинг" (конфликт интересов). **Действие:** Обязательное раскрытие, согласование через дирекцию.

5. **Red flag:** Подрядчик зарегистрирован менее 6 месяцев назад. **Действие:** Дополнительная проверка через директора по безопасности.

6. **Red flag:** Юридический адрес подрядчика — адрес массовой регистрации. **Действие:** Запрос пояснений у подрядчика.

7. **Red flag:** По данным отчётности у подрядчика отсутствует персонал при заявленных объёмах работ. **Действие:** Запрос пояснений + согласование через директора по безопасности.

## Заключительные положения

Настоящий чек-лист применяется совместно с Корпоративным стандартом работы с подрядчиками (Раздел III: Договорное оформление) и не отменяет иных процедур преддоговорной проверки, установленных Разделами I и II указанного стандарта.
